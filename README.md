# 3DMusic — Super Mario Pipe Generator

Генератор G-code файлов для печати 6 музыкальных модулей, из которых собирается цилиндр, воспроизводящий тему Super Mario.

**Live demo:** [https://chubarevgeniy.github.io/3DMusic/](https://chubarevgeniy.github.io/3DMusic/)

## Стек

- React 18 + TypeScript
- Vite
- Tailwind CSS

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

При каждом пуше в ветку `main` GitHub Actions автоматически собирает проект и публикует его на GitHub Pages.
